# Spec: License the repository under MIT

## Design

Add a root `LICENSE` file containing the standard MIT license text from GitHub's MIT license template, with `Copyright (c) 2026 Olaf Krasicki-Freund`. A root license file provides the requested repository license and enables GitHub license detection.

The repository is already public. Keep application files, `flake.nix`, and `manifest.json` unchanged; this task changes repository licensing only.

## Alternatives rejected

- A README statement alone: does not provide the full license terms in a dedicated file.
- A different license or custom terms: conflicts with the owner's explicit MIT request.

## Risks

An altered license template or incorrect copyright notice could prevent accurate license detection. Preserve the standard template wording and use the copyright holder and year from the approved intent. No runtime or host configuration changes are involved.

## Verification
