## Decisions (from the approved spec)

1. **Which pull requests.** Open pull requests you authored or were
   directly asked to review, across github.com: up to 50, archived
   repositories excluded, most recently updated first.
   - One request per refresh. The search string is fixed:
     `is:pr is:open archived:false sort:updated-desc (author:@me OR user-review-requested:@me)`.
   - It uses `search(type: ISSUE_ADVANCED, first: 50)`. Team review
     requests are not included.
2. **Query.** `PRS_QUERY` is the spec's fixed GraphQL text (copied below).
   Its only variable is `$q`. It has no `rateLimit` and no `updatedAt`.
   - The request is `gh api --hostname github.com --include graphql -f
     query=PRS_QUERY -f q=PRS_SEARCH`, built as an argv array, through
     `request(endpoint, include, method, fields)`.
   - Measured: 1 point and about 145 KB at the caps. A GraphQL error is
     HTTP 200 with `errors`, and `gh` exits 1.

   ```graphql
   query($q: String!) {
     search(query: $q, type: ISSUE_ADVANCED, first: 50) {
       issueCount
       nodes { ... on PullRequest {
         number title isDraft headRefName headRefOid url
         repository { nameWithOwner }
         commits(last: 1) { nodes { commit { oid statusCheckRollup { state
           contexts(first: 50) { totalCount nodes { __typename
             ... on CheckRun { name status conclusion detailsUrl
               checkSuite { repository { nameWithOwner } workflowRun { databaseId } } }
             ... on StatusContext { context state targetUrl } } } } } } }
       } }
     }
   }
   ```
3. **Helper `read_prs(task)`**, for page kind `prs`. `read_page` calls it
   before `page_endpoint`.
   - **Input:** only `kind`, `page` and `requestId` are accepted, and
     anything else is `ValueError`. Types are checked exactly, as in
     `page_endpoint`: `type(page) is int and page == 1`, because
     `True == 1`; `requestId` is an int ≥ 1.
   - **`request(endpoint, include=False, method=None, fields=None)`**:
     - each field appends `-f`, `name=value` after the endpoint;
     - existing callers are unchanged;
     - one test asserts the exact `Popen` argv.
   - **Result:** the `read_page` shape plus `resource:"graphql"`, which is
     set at creation so it is on every return. Only fixed strings and parsed
     values are returned, never the body or a GraphQL `message`.
   - **Order:**
     1. A transport failure or a missing `gh` gives the existing fixed
        errors.
     2. Run `http_reply` and `rate_headers`.
     3. HTTP ≥ 400 follows the REST rules. The 403/404 text is "Pull
        requests unavailable; token cannot search them".
     4. HTTP 200: the body must be JSON, else it is invalid data
        (`network`). `errors`, when present, must be a list of dicts. Each is
        classified:
        - rate: `type=="RATE_LIMITED"`;
        - access: `type` `FORBIDDEN`, or `SAML` in `type` or `message`;
        - other: anything else.
     5. **Usable data** means `data.search` is a dict and `nodes` is a list.
        - Without it and without errors, the reply is invalid data
          (`network`).
        - Without it but with errors, the first error decides, even
          when `search` is missing: rate → `rate`; access →
          `permission`, "Pull requests unavailable; token or SSO refused";
          otherwise `network`, "GitHub returned an error for pull
          requests".
        - With it, the reply is kept whatever the exit code. Errors whose
          `path` starts with `["search","nodes",i]` (i an int) mark that
          node `unavailable`. Any rate error also sets `errorType:"rate"`
          with `data` kept. Pathless non-rate errors set `partial:true`.
   - **Parsing:** `i` is the original `enumerate` index, taken before
     skipping.
     - Nodes are skipped when they are not dicts, have no int `number` ≥ 1,
       or have a `repository.nameWithOwner` that `repo_name` refuses.
     - Each pull request is `{repo, number, title, branch, draft, url, sha,
       checks}`:
       - `title` is `plain()` cut to 200, `branch` is `plain()` cut to 100,
         and `draft` is `isDraft is True`;
       - `url` is kept only if it equals
         `https://github.com/<repo>/pull/<number>`, else `""`;
       - `sha` is `headRefOid` if it is 40 hex characters, else `""`.
     - `checks` is one of:
       - `{state:"unavailable"}` on a node error, a missing `sha`, or a last
         commit `oid` that is not `sha`;
       - `{state:"none"}` only when the matching commit's
         `statusCheckRollup` key is present and `null`;
       - otherwise `{state, total, items}`:
         - `state`: `SUCCESS` → `success`, `FAILURE`/`ERROR` → `failure`,
           `PENDING`/`EXPECTED` → `pending`, and anything else (including a
           malformed rollup) → `unavailable`;
         - `total`: `contexts.totalCount` if it is an int ≥ 0, else the
           number of items.
     - **Items** are `{name, status, conclusion, url, repo, run}`:
       - **CheckRun:**
         - `name`: a string, `plain()`, cut to 100;
         - `status`: lower-cased, within `queued in_progress completed
           waiting pending requested`, else `unknown`;
         - `conclusion`: lower-cased, within `success failure neutral
           cancelled timed_out action_required skipped stale
           startup_failure`, else `""`;
         - `url`: `detailsUrl`;
         - `repo`: the check suite's `nameWithOwner` if `repo_name` accepts
           it, else `""`;
         - `run`: `workflowRun.databaseId` as a string if it is an int ≥ 1,
           else `""`.
       - **StatusContext:**
         - `name`: `context`, as a string, `plain()`, cut to 100;
         - status and conclusion by `state`:
           - `SUCCESS` → `completed`/`success`;
           - `FAILURE` or `ERROR` → `completed`/`failure`;
           - `PENDING` or `EXPECTED` → `pending`/`""`;
           - anything else → `unknown`/`""`;
         - `url`: `targetUrl`;
         - `repo` and `run`: `""`.
       - **Other types** are skipped, but still count in `total`.
     - **Links:** a string is kept only if `plain()` leaves it unchanged,
       else `""`.
   - **Data:** `{list (≤ 50), total, partial}`. `total` is `issueCount` if
     it is an int ≥ 0, else the length of the list. Missing or invalid
     `data.search` is "invalid data" (`network`).
4. **Scheduler state:**
   - `create()` gains:
     - `prView:false`;
     - `prs:{list:null,total:0,at:undefined,error:"",partial:false}`;
     - `gqlRemaining:null`, `gqlResetAt:0`.
   - `TIMING` gains `prs:60000` and `prsActive:15000`.
   - There is one task, `prs::`: kind `prs`, no repo, group `interactive`.
5. **Scheduler rules:**
   - **`view(s,on,now)`** sets `prView` and clears `wakeAt`. When `on` is
     false and the task is not in flight, it deletes the `prs` task.
   - **`seed`**, only while `opened && prView && accountVerified`:
     - `due = age(prs.at, (any pending ? prsActive : prs) * gqlPace(s,now))`;
     - the task is created only `if (now >= due)`;
     - a queued `prs` task is deleted while the view is off or the login is
       unverified.
   - **`next()`** sends `{kind:"prs",page:1,requestId}` only, with no `repo`
     or `run`.
   - **Quota:** `completeReply` writes `gqlRemaining`/`gqlResetAt` when
     `reply.resource==="graphql"`, and otherwise `remaining`/`resetAt`.
     - `gqlPace` is `pace()` over the GraphQL pair; `pace()` stays
       REST-only.
     - `cool()` is unchanged and shared.
   - **`completeReply` for `prs`** runs before the shared error block and
     never sets `s.error`.
     - "Invalid data" requires an object with an array `list`.
     - **Usable data** (including a rate reply that has rows):
       1. store `list`, `total`, `partial` and `at=now`;
       2. set `error` to "Some checks could not be read" when `partial`,
          else `""`;
       3. delete the task.

       `completeReply` already calls `cool()` once, before any per-kind
       branch (line 327). Do not call it again: a second call would
       double-count `rateFailures`.
     - **Errors without data:**
       - `prs.error = reply.error`;
       - `auth` and `setup` set `s.auth`;
       - `rate` and `network` keep the task with the existing backoff and
         cooldown;
       - `permission` sets `prs.at=now` and deletes the task.

       No error blocks a repository.
   - **Account:**
     - The login-change reset also resets `prs`, and sets
       `gqlRemaining=null`, `gqlResetAt=0`. It keeps `prView`.
     - The account `permission` branch also resets `prs`.
   - **`manual`**, while `prView`, is a branch at the very top, after
     `wakeAt=0` and `auth=false`. It goes before the `catalogueBlocked`
     clause (line 74), which would otherwise set `discover`. The branch:
     1. checks the account as today (the account task, due now);
     2. makes `prs` due now (`restart` when queued, else `ensure`);
     3. returns.

     The `catalogue` flag is ignored in the view.
   - **Unchanged and relied on:**
     - the one-second reseed in `next()`;
     - the slot rotation (line 188);
     - account-first dispatch (`next()` holds other kinds until
       `accountChecked`);
     - the shared cooldown and the bar's paused state;
     - cached rows staying on a `prs` error.
   - **`jump(s,repo,run,expanded,now)`**:
     1. `view(s,false,now)`;
     2. `select(s,repo,run,expanded,now,true)`;
     3. `touch(s,repo,run,now)`.
6. **Model:**
   - **`prRows(prs, expanded, filter, now)`**:
     - **Every row** carries `kind`, `key`, `parent`, `depth`, `title`,
       `subtitle`, `status`, `statusText`, `info`, `repo`, `url`, and on
       checks `run` and `external`. A `pr` row has `depth:0`, `parent:""`;
       a check or check-more row has `depth:1` and the PR key as `parent`;
       the final list-more row has `depth:0`. The panel uses `parent` for ←
       and `depth` for indentation.
     - **`pr` rows:**
       - key `pr:<repo>#<n>`;
       - title `<repo> #<n> <title>`, with `Draft · ` in front for a draft;
       - subtitle: the branch;
       - status:
         - `success` → `success`;
         - `failure` → `failure`;
         - `pending` → `in_progress`;
         - `none` → `""`, statusText "no checks";
         - `unavailable` → `error`, statusText "checks unavailable";
       - statusText otherwise via `label()`;
       - `info`: `N checks`, plus "checked 40s ago" or "checked 3m ago"
         when `now - prs.at` is over the refresh interval. The interval is
         15000 ms when any listed pull request is `pending`, else 60000 ms.
         Model constants `PR_REFRESH=60000` and `PR_REFRESH_ACTIVE=15000`
         are kept equal to Polling's `TIMING.prs`/`prsActive` by
         `tests/model.cjs`. Seconds are used below a minute;
       - `url`: only if `browsable`, and `repo`.
     - **`check` rows**, under an expanded pull request:
       - key `<prkey>:<index>:<name>`, title: the check name;
       - status `state(item)`, statusText `label(state(item))`, `info:""`;
       - `url`: only if `browsable`;
       - `external`: true when there is a non-github.com link;
       - `repo` and `run`.
     - **"More" rows** (`kind:"more"`):
       - after a PR's checks, only when `total > items.length`: "N more
         checks on GitHub", url `<pr url>/checks`, or `""` without a
         pull-request link;
       - at the end of the list, only when `prs.total > list.length`: "N
         more on GitHub", url `https://github.com/pulls`.
     - **Filter:** repository, title, branch and status text for a pull
       request, and name and status for a check. A pull request with a
       matching check is shown with that check.
   - **`prEmptyText(state)`**, the first that applies:
     - "Verifying your GitHub login…" before `accountChecked`;
     - "Pull requests need a verified GitHub login; check gh auth status"
       when `accountChecked && !accountVerified`;
     - `prs.error` when the list is `null` and there is an error;
     - "Loading pull requests…" when the list is `null` with no error;
     - "No open pull requests";
     - `No match for "x"`.
   - **`prStatusLine(s,now)`** returns the same `{text, urgent, quota}`
     shape as `statusLine` (`urgent` when there is an error or a pause):
     - the notice;
     - `prs.error`;
     - "GitHub paused until …" during the cooldown;
     - "N open pull requests";
     - quota `quotaText(gqlRemaining,gqlResetAt,now,"GraphQL points")`.
       `quotaText` gains an optional label, defaulting to "API requests".
   - **`accessibleName`** covers `pr` ("pull request: …, expanded/collapsed")
     and `check`.
